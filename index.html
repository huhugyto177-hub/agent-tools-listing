Choose like an operator, not a tourist.

        
A listing tells you what exists. Before wiring anything into a production agent, run the checks that discovery pages usually skip.

      

      

        
Define the exact “use when.”Write the task, inputs, expected output and stop condition before selecting a tool. One October Bazaar snapshot found 94% of listings missing a “use when” line.

        
Check the current response contract.Confirm version, auth, schemas, errors and timeouts against the tool’s current documentation. This catalog is a dated snapshot, not an uptime monitor.

        
Cap spend outside the prompt.Use deterministic limits, idempotency and a human threshold. Model instructions alone are not a reliable money-control boundary.

        
Test the second call.One successful response does not establish repeatability. Probe retries, duplicate requests, changed prices and changed payees before production.

        
Keep an outcome receipt.Record instruction, authorization, intent, decision and outcome so a failure can be reconstructed later.

This catalog is built from web research completed October 14, 2026. Entries are included because the research identified them as concrete protocols, projects or product categories—not because this page independently verified current uptime, security, pricing or availability.
